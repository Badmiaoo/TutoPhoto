const RESUME = {
  type: 'object',
  properties: {
    fichier: { type: 'string' }, pousse: { type: 'boolean' }, resume: { type: 'string' },
    constats: { type: 'number' }, verifies: { type: 'number' },
  },
  required: ['fichier', 'pousse', 'resume', 'constats'],
}
const VERDICTS = {
  type: 'object',
  properties: {
    pousse: { type: 'boolean' }, confirmes: { type: 'number' }, refutes: { type: 'number' }, ajoutes: { type: 'number' },
    resume: { type: 'string' },
  },
  required: ['pousse', 'confirmes', 'refutes', 'resume'],
}
const keys = (args && args.lots) || Object.keys(LOTS)
const out = []
let coupe = false
for (const key of keys) {
  const l = LOTS[key]
  let audit = l.deja ? { fichier: l.fichier, pousse: true, resume: l.perimetre, constats: 20 } : null
  if (!l.deja) {
    audit = await agent(`${COMMON}

Mission : auditer le lot « ${l.titre} » et pousser ton rapport.
Périmètre : ${l.perimetre}

Écris ${W}/${l.fichier} (français), au fur et à mesure :
- en tête : date, périmètre, méthode, sources relues et non relues, et la ligne « État : constats non contre-vérifiés » ;
- section « Constats » : un constat par titre de niveau 3, « ### ${l.prefixe}-01 · gravité · titre », gravité parmi « faux » (contraire à la source ou au calcul), « non sourcé », « incohérent » (code, documentation et fiches ne disent pas la même chose), « à améliorer » (juste mais trompeur, obscur, irréaliste sans être dit, ou source de dette) ; puis l'endroit exact (fichier et ligne), ce qui est écrit ou fait, la preuve (citation exacte de la source avec son adresse, calcul refait avec ses nombres, extrait de code, mesure), et la correction proposée, précise ;
- section « Vérifié » : les points contrôlés et justes, une ligne chacun ;
- section « Je ne sais pas » : ce que tu n'as pas pu vérifier, et pourquoi.
Classe les constats du plus grave au moins grave. Pas de constat sans preuve. Pousse à mi-parcours et à la fin.

Réponds par l'objet structuré : fichier, pousse (vrai si ton dernier état est poussé), resume (120 mots au plus), constats (nombre), verifies (nombre).`, { label: `audit ${key}`, phase: 'Audit', schema: RESUME, agentType: 'general-purpose' })
    if (!audit) { coupe = true; out.push({ lot: key, etape: 'audit coupé' }); break }
  }
  const refutation = await agent(`${COMMON}

Mission : essayer de réfuter, un par un, tous les constats du rapport ${W}/${l.fichier} (lot « ${l.titre} »), écrit par un autre agent, puis pousser le rapport annoté.
Tu es l'avocat du travail audité. Pour chaque constat (titres « ### ${l.prefixe}-… ») : relis toi-même l'endroit visé et la source à son adresse, ou refais le calcul avec ton propre script (sous ${S}/audit/${key}/refutation/), et cherche si le constat est faux, exagéré, déjà dit ailleurs dans le dépôt, ou si sa correction introduirait une erreur ou une dette. Dans le doute, le constat est réfuté.
Écris sous chaque constat une ligne « **Contre-vérification : confirmé.** » ou « **Contre-vérification : réfuté.** », suivie de ta preuve en une ou deux phrases ; corrige la correction proposée quand elle est fausse ou disproportionnée. Si tu trouves en chemin une faute que le rapport n'a pas vue, ajoute-la en fin de section « Constats » avec la mention « ajouté à la contre-vérification » et sa preuve. Remplace en tête la mention d'état par le bilan : date, constats confirmés, réfutés, ajoutés. Retire toute note qui dit que le rapport n'est pas contre-vérifié. Pousse à mi-parcours et à la fin.

Réponds par l'objet structuré : pousse, confirmes, refutes, ajoutes (nombres), resume (120 mots au plus : ce qui est vraiment à corriger, du plus grave au moins grave).`, { label: `réfutation ${key}`, phase: 'Réfutation', schema: VERDICTS, agentType: 'general-purpose' })
  out.push({ lot: key, fichier: l.fichier, audit: audit ? { resume: audit.resume, constats: audit.constats, verifies: audit.verifies } : null, refutation })
  log(`${key} : ${refutation ? `${refutation.confirmes} confirmé(s), ${refutation.refutes} réfuté(s)` : 'contre-vérification coupée'}`)
  if (!refutation) { coupe = true; break }
}
let synthese = null
if (!coupe && (!args || args.synthese !== false)) {
  synthese = await agent(`${COMMON}
Pour cette mission, ton périmètre d'écriture s'étend à ${W}/docs/etat-des-travaux.md.

Mission : écrire la synthèse de l'audit et le plan de corrections, puis pousser.
Lis tous les rapports de ${W}/docs/audit/ (constats et contre-vérifications). Écris ${W}/docs/audit/README.md (français) :
- ce qui a été audité, par qui et comment (un agent, puis un second qui réfute), et ce qui ne l'a pas été ;
- un tableau des constats confirmés, tous lots confondus, du plus grave au moins grave (identifiant, gravité, ce qui est faux, où) ; le nombre de constats réfutés et de points vérifiés par lot ;
- le plan de corrections : des pull requests ordonnées, une par sujet, chacune avec les constats qu'elle traite, ce qu'elle change, ce qui la protège des régressions, et ce qu'il faut demander à Julien avant (décisions, sources qu'il doit relever) ; les refontes d'architecture d'abord quand d'autres corrections en dépendent ;
- ce qui reste « Je ne sais pas ».
Mets à jour dans ${W}/docs/etat-des-travaux.md le tableau « Nouvel ordre de travail » du point du 13 novembre : état de chaque lot d'audit, et renvoi au plan de corrections. Ne change rien d'autre dans ce fichier.
Commit (git add docs/audit docs/etat-des-travaux.md), contrôle, push.

Réponds par l'objet structuré : fichier, pousse, resume (150 mots au plus : les cinq corrections les plus importantes et la première pull request à faire), constats (nombre de constats confirmés au total).`, { label: 'synthèse', phase: 'Synthèse', schema: RESUME, agentType: 'general-purpose' })
}
return { lots: out, coupe, synthese }
